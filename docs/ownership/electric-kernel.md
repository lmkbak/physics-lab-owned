## Public contract

Named exports: `GMIN`, `solveLinear`, `Resistor`, `Source`, `Supply`, `Diode`, `Lamp`, `Capacitor`, `Motor`, `solveStep`.

- `solveLinear(A, b)` takes a square finite real matrix and right hand side and never modifies either input. Returns a finite solution vector for full-rank or consistent rank-deficient systems; free coordinates are set to zero. Returns `null` for an inconsistent or non-finite system. Invalid dimensions throw. Empty input returns `[]`. Lead confirmed this singular-system convention.
- `Resistor(a,b,R)` returns a passive two-terminal resistor.
- `Source(p,n,E,r)` returns a Thevenin source. Public `current(V)` is delivered current `(E-(Vp-Vn))/r`; an absorbing battery has negative current.
- `Supply(p,n,Vset,Ilim,r=.02)` returns a regulated supply. Delivered current is `min((Vset-U)/r,Ilim)`. `mode` is `CC` when the forward current limit is active, otherwise `CV`. Positive reported current means forward output; negative current represents reverse-feed absorption. Lead supplied black-box behavioral facts: Vset=3, r=.02, U=3.1 gives -5 A and U=6 gives -150 A. This fixes the reverse-feed branch without reading the legacy solver. The current limit is one-sided, not an absolute-value clamp.
- `Diode(a,k,m,{Vf,If,n=2,Rs=1,Bv=1e9})` exposes its series-resistance internal node `m`. Planned calibration: the terminal characteristic passes exactly through `(Vf,If)`, including the series resistance. `Vf-If*Rs` therefore calibrates the intrinsic junction drop. Lead confirmed the terminal nominal drop includes the series-resistance drop.
- `Lamp(a,b,Vr,Ir,c=.18)` is symmetric, passes exactly through `(+Vr,+Ir)` and `(-Vr,-Ir)`, and has cold resistance `c*Vr/Ir`. It has finite slope at zero and positive incremental resistance everywhere.
- `Capacitor(a,b,C,state={v:0})` shares the supplied state object. The previous accepted `state.v` is the history source, independent of the initial Newton voltage guess. A converged positive-time step commits the new terminal voltage only after the entire solve is accepted. `current(V)` retains the accepted step's history voltage so reporting after the commit remains correct. Isolated capacitors retain charge without a permanent numerical shunt. When the upper layer changes C between rebuilt element instances, it must rescale the externally owned history voltage as `v_new=v_old*C_old/C_new` if charge is to remain constant; a fresh constructor has no old-C information and must not invent it.
- `Motor(a,b,{Ra=3,k=.01,J=2e-5,damp=2e-6,Tf=.002},state)` shares `state.w` and `state.stalled`. Positive armature voltage produces positive torque/speed. Stalling fixes speed to zero; current and torque remain `U/Ra` and `k*I`. Dry friction holds the rotor at rest below breakaway torque and opposes motion in either direction. Accepted time steps alone update speed and `state.angle`; backward Euler angle integration is `angle_next=angle_previous+dt*w_next`. Existing unrelated state fields are retained.
- Every element exposes `.nodes`, `.kind`, `.current(V)`. Resistor/lamp/capacitor/motor/diode current is positive from the first external terminal to the second. Voltage lookup maps every negative node to 0 V. Construction returns the object that `net.add` can return unchanged, allowing `p.el.current(net.V)`.
- `solveStep(n,elements,{dt,V,refs,debug})` returns `{V,iterations,converged}`. Input voltage arrays are copied. `n` is the number of nonnegative node unknowns. `dt` defaults to 1/60 s; zero time means no dynamic state advance. At dt=0 each capacitor enforces `Va-Vb=state.v` using one extra branch-current unknown and an exact voltage-constraint row; the resulting instantaneous constraint current is reported (zero if isolated). It never divides by zero, opens a charged capacitor, or overwrites state. Conflicting frozen voltage constraints return nonconverged. Motor speed is held at prior w (or zero if stalled), with angle unchanged. Lead confirmed `refs` is an array of node numbers, one zero-voltage reference per independent connected component; it does not request per-node leakage. Missing gauges are selected deterministically for otherwise floating components. No logging is emitted by default; debug never changes model equations.

Units: volts, amperes, ohms, farads, seconds, rad/s, N m, kg m², SI motor constants. Values and nodes must be finite and physically valid; default models have no hidden network-wide voltage clamp.

## Independent constitutive equations

Write `U=Va-Vb` and let `i` be current leaving the first terminal. A branch contributes `+i` and `-i` to the two KCL rows. Its differential conductance contributes the symmetric two-node Jacobian stencil.

1. Resistor: `i=U/R`.
2. Thevenin source: passive KCL current `i=(U-E)/r`; report its negative as delivered current.
3. Supply: passive KCL current is the negative of delivered current. CV uses slope `1/r`; forward CC uses zero slope. Reverse-feed absorption remains on the CV line with slope `1/r`; no lower current clamp is applied. Mode is updated after the accepted solution, not inside rejected Newton evaluations.
4. Diode: resistor from `a` to `m`, junction from `m` to `k`. Intrinsic forward current is `Is*expm1(u/(n*VT))`, `VT=0.02585 V`. Calibrate `Is` from the declared nominal point. Model avalanche using a separate reverse exponential activated near `-Bv`, continuous at zero and negligible below breakdown. Limit exponent evaluation with a continuous linear tail, retaining finite current and derivative instead of overflowing. Newton line search controls actual node movement; the final KCL residual is evaluated against the same full equations.
5. Lamp: implement the lead-specified observable compatibility characteristic `i=U/[Rr*(c+(1-c)*sqrt(abs(U)/Vr))]`, `Rr=Vr/Ir`. With `t=sqrt(abs(U)/Vr)` and `d=c+(1-c)*t`, the independently differentiated Jacobian is `g=(c+(1-c)*t/2)/(Rr*d*d)`; at zero it is exactly `1/(Rr*c)`. This is an odd monotone teaching experience law with exact nominal calibration, finite cold slope and rising static resistance; it is not certified real-bulb measurement. Source: lead public-interface observations and explicit lead formula requirement, received after initial independent implementation. No old source was read.
6. Capacitor backward Euler: `i=(C/dt)*(U-v_previous)`. Store a frozen step-history value for all Newton trials and reporting. There is no deliberate leakage resistor.
7. Motor: `i=(U-k*w)/Ra`; `J*(w-w_previous)/dt=k*i-damp*w-Tf*sign(w)`. Eliminate `i` to obtain `w=softThreshold((J/dt)*w_previous+k*U/Ra,Tf)/(J/dt+damp+k*k/Ra)`. This implicit update couples back EMF to the same accepted electrical solution, is symmetric under polarity reversal, handles static friction, and supplies an analytic incremental conductance. Stalled state sets `w=0` before electrical evaluation. Public current reporting uses the accepted speed.

## Linear solve and nonlinear solve design

The linear kernel copies inputs, equilibrates rows and columns, then applies Gaussian elimination with complete row/column pivoting and records the variable permutation. Rank thresholds are `8*Number.EPSILON*max(1,n)` on equilibrated coefficients rather than a fixed physical pivot. Original-equation residual checks distinguish consistent singular systems from contradictory equations and protect against returning non-finite answers; acceptance requires each row error <= `1e-10*(abs(b_i)+sum(abs(A_ij))*max(abs(x)))`. This row-norm backward error avoids spuriously rejecting cancellation in zero-right-hand-side correction equations. Zero rows retain their own RHS-only bound; the explicit contradictory tiny row `[[1,0],[0,0]] x=[1,1e-20]` is tested and returns null. Planted-voltage and weak-mode voltage/current oracles separately guard against a large row hiding a physical low-current error. The implementation uses pivoted elimination plus explicit residual verification; it does not need iterative refinement for the independently tested matrices.

The nonlinear kernel builds node KCL and analytic branch derivatives from the new element models. It removes explicit reference nodes from unknowns. For each connected component with no physical ground or declared reference, it chooses one gauge node; this removes only common-mode indeterminacy and does not introduce artificial charge leakage. Truly empty nodes receive a deterministic zero reference.

Start from a copied finite voltage guess. Without a finite caller guess, construct a spanning-tree guess prioritizing source voltages and capacitor history, then zero-drop passive edges; this sets only an initial common-mode guess. Supply seeds start on the CV branch; diode seeds bound only the internal junction's initial drop. Neither seed constrains any accepted voltage. This avoids a singular all-CC open-supply start and a misleading forward-biased dangling LED start. Assemble the residual/Jacobian, solve `J*delta=-F`, restrict an excessively large trial update, and apply backtracking based on the scaled KCL residual. A failed line search may use numerical diagonal regularization based on `GMIN` for the correction equation only; the unregularized residual remains the acceptance criterion. Iteration cap is 120. For each KCL row j compute `absFloor_j=min(1e-9 A,max(1e-30 A,(1e-10 V)*sum(abs(branch incremental conductance_j))))` and `scale_j=absFloor_j + 1e-7*sum(abs(physical stamped branch current_j))`; current acceptance is `max(abs(F_j)/scale_j)<=.01` (100 times tighter than the initial contract ceiling). The conductance-sensitive floor prevents a pF capacitor history current from disappearing below a fixed ampere tolerance. For a single capacitor-only island this conductance-scaled condition implies `abs((dt/C)*F_j)<=1e-10 V/(1-1e-7)`; this is a voltage/charge conservation condition rather than a large fixed current allowance. Independent pF tests additionally assert stored voltage error <=1e-10 V across 100 steps and zero branch current <=1e-22 A. Voltage-constraint rows use `1e-10 V+1e-8*max(abs(Va),abs(Vb),abs(v_history))`. Newton step convergence additionally requires `max(abs(deltaV_j)/(1e-9 V+1e-8*max(abs(V_j),abs(V_j+deltaV_j))))<=1`, except an already exact residual may accept before making any correction. Trial backtracking uses the maximum scaled residual with scales frozen from the current Newton iterate; a falling exponential residual must not lose its measured progress because a trial recomputed the denominator. Each accepted iterate recomputes physical acceptance scales. The voltage step trust bound is `max(10 V,max(abs(current voltage)))`, allowing scale-aware progress without permanently clamping any node. A singular correction Jacobian may also receive temporary GMIN regularization before line search; all branch currents are from constitutive equations at the trial voltage, without a display-only current clamp. Analytic source and supply current-limiting equations themselves remain part of that physical residual. Nonconvergence returns a finite last candidate with `converged:false` and does not commit capacitor/motor state. No fallback silently swaps in another model or accepts a large residual.

Floating capacitor history requires no special leakage: its companion conductance and history current preserve the voltage difference while the selected gauge fixes only common mode. This is particularly important for the existing pF plate capacitor model.

## Independent acceptance matrix

Tests will import only the new owned kernel. They will assert numeric answers and invariants rather than compare against old implementation output.

- Linear known answer, input immutability, empty and consistent singular systems, contradictory system, mixed-scale and badly scaled equations.
- Source plus load and series/parallel networks using closed-form Ohm-law answers; delivered and absorbed source current signs.
- Supply CV/load boundary, CC, hard short with finite resistance, zero limit, external overvoltage/reverse feed.
- Lamp nominal point, both polarities, cold slope, increasing static resistance and curve shape.
- Diode nominal calibration, resistor-limited forward load, reverse cutoff and finite reverse breakdown behavior.
- Capacitor exact backward-Euler recurrence for charging/discharging, state history overriding guess, current after state commit, isolated charged pF capacitor, both terminals floating, rejected-step state immutability.
- Motor first-step closed form, forward/reverse symmetry, breakaway friction, steady speed/current, externally forced braking, stalled current/torque and nonzero previous speed forced to zero.
- Floating source/load network, disconnected components, self-connected branches, empty nodes, and finite failure behavior.
- Minimal synthetic net.add/report compatibility using the public construction and current-access patterns observed in parts.js.

## Quantitative oracle and execution gate

Executed command: `node tools/owned-electric/kernel.test.mjs` (19 groups passed, Node v22.14.0) using `node:assert/strict`, no production imports. The test command will fail on any assertion and print named case counts only; no application logs are changed.

Default algebraic oracle tolerance is `abs(error) <= 1e-9 + 1e-7*abs(expected)` for voltages/currents and `1e-10 + 1e-7*abs(expected)` for low-current diode/capacitor cases. Every converged network additionally checks external-terminal KCL to `1e-9 A + 1e-7*sum(abs(branch currents))`; semiconductor internal-node balance uses the same bound. Full-rank linear solves check scaled backward error <= `1e-12` for well-conditioned cases. Difficult scaling cases use <= `1e-9` and explicitly finite outputs.

Independent oracles and sweeps:

- DC: 3 V/1 ohm source and 10 ohm load -> `I=3/11`, `U=30/11`. Floating copies preserve identical differences to the same tolerance. Disconnected and unused nodes remain finite. A contradictory `[[1,1],[2,2]]*[x,y]=[1,3]` returns null; the consistent `[1,2]` gives zero for its free coordinate.
- CV/CC: sweep load resistance across `(Vset/Ilim)-r` at 0.5, 0.99, 1.01 and 2 times the boundary, plus 3 milliohm load. Oracle is `I=min(Vset/(R+r),Ilim)`, `U=I*R`, and the measured resistor current must equal supply current. A clamped report with excessive real network current fails. Reverse-feed direct-current oracles are -5 A at 3.1 V and -150 A at 6 V for Vset=3 and r=.02; a stronger parallel Thevenin source additionally checks actual KCL and reverse absorption.
- Lamp: sample `U/Vr` in `[-2,-1,-.5,-.01,0,.01,.5,1,2]`; substitute computed current into the stated lead-specified teaching characteristic and check residual to default tolerance, exact nominal point, odd symmetry, increasing `abs(U/I)` as voltage rises, and analytic conductance against a central finite difference. Fixed behavioral oracles are `I(.01*Vr)/Ir=.03816793893129771` and `I(.5*Vr)/Ir=.6580440430759857` to 1e-12 absolute.
- Diode: scan terminal bias from -12 V to the nominal point and above, both directly and through 1/10/1000 ohm series loads. At the nominal current check `Vf`, at each point substitute into the independently evaluated Shockley-plus-series relation; assert ordinary reverse-bias cutoff near `-Is`, with `Is=If/expm1((Vf-If*Rs)/(n*VT))`, `I<0`, `abs(I+Is)<=1e-10 A`, `abs(I)<=max(1e-8 A,1.01*Is)` and also `abs(I)<1e-6 A` (the specified silicon calibration implies Is approximately 4.72e-8 A, so a universal 1e-8 A cutoff would contradict its own Shockley oracle) and monotonic forward current. Reverse-breakdown tests use a deliberately small Bv and check finite monotonic avalanche current. Parameter sweeps cover the LED and silicon values constructed in parts.js.
- RC: exact discrete oracle is `v[k+1]=(v[k]+dt*E/(R*C))/(1+dt/(R*C))`; use `C=.001 F`, `R=100 ohm`, initial `v=1.25 V`, charge E=5 and discharge E=0. At one time constant compare with continuous `E+(v0-E)*exp(-t/(R*C))`, then halve dt twice; positive discretization error must decrease at approximately first order (ratio 1.7..2.3). Isolated pF capacitor voltage is invariant within `1e-10 V`, including floating terminals and a deliberately incorrect voltage guess. Current at the final candidate must be identical before and after the public commit. Upper-layer inverse-C voltage rescaling gets a separate charge-invariance assertion.
- Motor: first step at fixed U follows the closed-form soft-threshold equation in this document. At zero speed, below-breakaway `abs(k*U/Ra)<=Tf` means w=0. At locked rotor assert `w=0`, `I=U/Ra`, torque `k*I`, independent of stale prior speed. Unlocked steady state solves `k*I=damp*w+Tf*sign(w)` plus `U=Ra*I+k*w`; run positive and negative voltage and polarity reversal. After accepted steps check `angle_next-angle_previous=dt*w_next` and finite dissipative braking. State remains unchanged on any nonconverged solve.

`converged` means a finite accepted voltage vector with the unregularized KCL criterion satisfied, not merely finite output. A failed linear solve or nonlinear iteration returns `converged:false`, finite candidate V and unchanged dynamic state. There is no `ok` export in the supplied solver API.

## Additional executed verification

- `node tools/owned-electric/stress.test.mjs`: 537 converged solves. Includes 60 deterministic random source/resistor networks with voltages planted independently by Ohm's law, 30 random floating networks solved at two gauges, resistances spanning 1e-9..1e12 ohm, +/-10000 V initial semiconductor guesses, open-circuit supply, and 200-step fresh-vs-persistent dynamic construction.
- `node tools/owned-electric/parts-compat.test.mjs`: all 22 actual TYPES, all 12 actual PRESETS over default/A/B/off switching, 70 fixture runs and 7762 fresh-build reports passed. The harness reads the permitted public parts module, replaces its solver import only in an in-memory string, and imports a data URL. It never loads the legacy solver and leaves production files unchanged. It checks finite reports, external/internal KCL and convergence; this is API/topology compatibility evidence, not proof of all UI interactions or a legacy curve match.
- The extracted open-RC dangling-LED topology is retained in the stress test. With no current path its anode, resistor tail and internal junction must all equal cathode voltage within 1e-10 V and both series/junction currents must be <=1e-20 A. A cold naive-zero seed previously created an artificial forward bias and rank-deficient weak mode; the new spanning-tree seed satisfies its physical initial common mode. Additional explicit 0/+100/-100 V caller guesses exposed an approximate reverse-bias plateau; the final implementation therefore eliminates passive leaf trees exactly by KCL zero-current back-substitution (only resistor/lamp/diode branches; never capacitor/source/motor). Removed tree edges are omitted from the reduced Jacobian; reconstructed terminal/internal voltages are evaluated by the original constitutive currents. This is exact zero-current leaf reduction, not an approximate leakage or threshold cutoff. The fixture now checks every guess and prevents a merely finite near-open answer from passing.
