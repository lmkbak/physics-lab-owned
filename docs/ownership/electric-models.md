## Public interface

`models.js` exports TYPES, METER, EPS0, ntcR, ldrR, plateC, LAMP_RATINGS, LED_COLORS, shortValue. TYPES has exactly the 22 requirement IDs; each definition supplies id/name/prefix/cat/terms/params/state/props/build/report, thumbnail/procedural metadata and independent note. Term IDs, parameter defaults, initial states, control types/ranges/steps/options follow the requirements. Constructors share caller-owned state. Build receives `(part, net)`, returns elements through net.add and sets p.el/p.els as applicable. Network adapter offers node(key), internal(partId,label), add(element), used(partId,term), voltage(a,b), V. Report receives `(part, net, dt=0)` and returns numeric live quantities plus rows and warn. `p.live` is assigned by Simulation. Readouts retain signed values; display rows use A/V two decimals, 15 V one decimal, microampere zero decimals, ordinary I three decimals and U two decimals. Meter live fields include reading, range, unit, frac, U, I, rows, warn. Lead supplied public consumer shapes: LAMP_RATINGS[key]=[Vr,Ir]; LED_COLORS[key]={name,Vf,color}; METER={Rg,Ig,ammeter:{R1,R2},voltmeter:{R1,R2},galvanometer:{Rg,Ig}}. Additional live consumer fields are lamp ratio (rated power fraction), source short, rheostat iAP/iPB, capacitor electric field E, solenoid B, and supply mode 'CV'/'CC'. These are required compatibility fields. All three instrument definitions set meter:true so bench instrument panels and data recording discover them.

`Simulation` exports a named class with dirty=true, V=[], time=0, warnings=[], lastIterations=0. Methods: build(model), step(model,dt,substeps=4), report(model,dt=0), potential('part:term'). Models have parts `{id,type,params,state,label}` and wires `{id,a:{p,t},b:{p,t}}`; ready/meshes are unnecessary. Each terminal is a distinct solver node; each wire is a 0.01 ohm resistor and keeps w.el/w.I. Build preserves state and allocates diode internal nodes deterministically. Each connected electrical component (not each device) gets exactly one reference, preferring the first source negative terminal in that connected component, otherwise its first terminal. Multiple sources sharing a connected component do not each receive a pinned negative. No numerical leakage is added. Build snapshots previous terminal voltages by key for warm starts. Dirty rebuilding retains dynamic state, protection state, and labels.

A full multi-substep call is transactional: take a synchronous frame snapshot, solve using elements holding the caller-owned state object, and roll back all tentative mutations on any failure. Only an entirely accepted call publishes state, V, p.live, w.I, element contexts, warnings or time. A failed solve returns `{converged:false,...}` and retains the previous accepted frame; time and protection timers do not advance, no success warning/readout is published. Failure diagnostics are separate from warnings. Rollback restores caller object identities and exact own-key sets, dirty, build node/internal maps, element references, accepted contexts and modes as well as public frame data. Exceptions during construction/validation restore that same snapshot before propagating. Successful calls return `{converged:true,iterations,...}`. Zero-time refresh neither advances timers nor rotor angle.

## Independently derived models

- Sources and nonlinearity use owned kernel equations. Supply uses 0.02 ohm output resistance and real CV/CC limiting, including reverse-feed absorption. Battery keeps requested E/r. Switch contact 0.01 ohm; open is an absent branch. DPDT A/B closes C1-to-selected1 and C2-to-selected2, off removes both.
- Fixed resistors 10/20/50 ohm. Rheostat splits Rmax at s, includes a common C/D slider node via 0.01 ohm contacts, and clamps zero-length resistance to 0.01 ohm. Decimal box is sum(d[i]*10**(3-i)), with 0.01 ohm contact floor. NTC is 100*exp(3950*(1/(T+273.15)-1/298.15)); LDR public teaching curve is 10000/(1+E/10), ohms at lux E. These are declared educational calibrations.
- Meter head Ig=0.001 A, Rg=100 ohm. Ammeter has head between low terminal and common, R1 from low to high, R2 from high to common. Let S=Ig*Rg/(0.6-Ig), then R2=Ig*(Rg+S)/3 and R1=S-R2. These follow head-current division for both inputs; no resistance table is copied. Voltmeter head Rg is fed by low-series R3=3/Ig-Rg, and high-to-low R15=(15-3)/Ig. Hence 3 V input resistance is 3000 ohm and 15 V input resistance is 15000 ohm. Reading is signed head current multiplied by selected full scale/Ig. Both positive inputs wired generate an explicit wiring warning. Galvanometer is 100 ohm with signed +/-300 microampere full scale.
- Lamp ratings contain (2.5 V,.3 A), (3.8 V,.3 A), (6.3 V,.15 A). Use kernel's odd nonlinear heating law i=U/[Rr*(c+(1-c)*sqrt(abs(U)/Vr))], Rr=Vr/Ir,c=.18, and brightness derived from normalized electrical power. This observable curve was supplied by Lead as a public behavioral requirement after contract approval; its derivative and implementation are independently calculated, with no reading of a legacy implementation. Accumulate excessive-load exposure only above 1.5 rated power, burning after 0.35 s; damaged lamp is open until replacement. LED has red/yellow/green/blue/white nominal drops 1.9/2/2.1/3/3 V at .02 A, n=2, Rs=2 ohm, reverse breakdown 5 V. Silicon diode uses .7 V at .02 A, n=2, Rs=1 ohm, Bv=50 V. LED overcurrent above .03 A or reverse bias beyond -5 V accumulates exposure, burns after .15 s, and stays open until replacement.
- Fuse uses .05 ohm, heat integrates max(0,(abs(I)/rating)**2-1) per second with 0.5/s cooling below rating; blows at heat>=1 and remains open until replacement.
- Plate capacitance EPS0*A*epsilonR/d with EPS0=8.8541878128e-12 F/m, declared plate area .0144 m², d mm, epsilonR=4 if inserted and 1 otherwise. Electrolytic is C microfarad. Rebuilding after capacitance changes conserves Q=C*v; if caller already rescaled v, tracked previous accepted v/C distinguish that from an unchanged v to avoid applying conservation twice. Explicit caller voltage changes/discharge take precedence. Capacitor state v and Q remain persistent. Electrolytic warnings fire below -0.5 V and above +16 V; no fabricated explosion model.
- Motor uses kernel Ra=3,k=.01,J=2e-5,damp=2e-6,Tf=.002; params.stalled is authoritative; report includes speed w, rpm, angle, back EMF, torque and copper/mechanical power. Stall warns when energized. Solenoid educational model is 8 ohm DC winding, 500 turns / .12 m, relative core multiplier 80 (air=1); B=mu0*muR*N*I/l with signed field and pole indication.

## Warning and protection behavior

Every live.warn entry has `{level,text}`; simulation warnings additionally identify part id. Meters report reversed connection for negative deflection and overload above full scale, without clamping numeric readings. Supply CC and reverse-feed are explicit. Battery excessive current, rheostat above selected 2/1.5/1 A rating, galvanometer overload, fixed-resistor dissipation above 2 W, capacitor polarity/voltage, fuse/lamp/LED damage, and energized motor stall have deterministic warnings. A newly burnt/blown part triggers a same-time rebuild and solve so published current is already zero. Parameter controls retain replace/discharge keys expected by bench; caller resetting state re-enables the component.
