## Public items contract

Exports DEFS (all 25 exact baseline keys), async createItem(key,ctx,opts={}), updateVesselVisual(item,dt,time,ctx), refill(item), bottleKey(reagent), mouthWorld(item,out?). Inputs ctx={scene,env,studio,proxyMat,fxGlow?,fxSoft?,onPop?}; opts includes def for dynamic owned-CAD definitions, reagent, studio and optional explicit owned scene data/load function for isolated tests. Missing assets/groups/profile fail with an actionable error, never render an unrelated placeholder as a claimed CAD equivalent.

Common item fields: id,key,def,name,kind,root:Group,proxy:Mesh with userData.item, mats:Material[], h/r in metres, gripY, sockets:{p:Vector3,accepts,occupant:null}[], stoppers:Object3D[], source,reagent,heldBy,socketOf,open,hover. createItem leaves positioning/scene addition to bench. Geometry is local metres from new CAD Z→Y adapter. Per-item geometry/material/resources are owned and item.dispose() is idempotent. Cloning the root after temporarily removing cyclic proxy.userData.item supports bench inspect, with independent cloned liquid ShaderMaterial uniforms.

Vessel fields: profile,capacity,mix,liquid,liqMat,level,col,pptCol,tint,turb,settle,stir,glow,lum,lastPpt,app,appT,bubbles,ppt,seeds,chunks,chunkKey,sodium,sodiumPos. Particles expose n and mesh/points as applicable; finite counters and bounded pools. Liquid has required uniforms uLevel/uCenter/uTime/uColor/uOpacity/uTurb/uPpt/uGlow/uBoil; shader is newly authored. Liquid geometry uses createLiquidGeometry(profile) with actual mL, not an arbitrary cylinder. Cavity local radius/height constraints apply to bubbles/precipitates/chunks; free surface stays at analytic local level. Wet/dry/zero volumes remain finite. Rebuilding volume geometry disposes the previous geometry, update at unchanged volume never allocates geometry/material. Clipping/alpha handles inspect uniforms and front/back glass readability.

Tool fields: tool.type dropper/rod/loop/spoon/splint, load:null, reagent:null, ion:null,charge:0,burn:null,shown:false. Spoon has spoonMesh children with mutable standard material; splint has state/life/ember/flame/charMat. Lamp flame has on/group/light/update/dispose and expected mutable color/intensity interfaces discovered solely from bench; wash exposes nozzle:Vector3. Socket locations are derived from new CAD groups or new independently selected functional specifications rather than copying old mesh coordinates. The bench's compatibility flame anchor y=.0915m is a consumer constraint, so lamp wick must be aligned there or documented adapter offset supplied.

## Spectacle contract

Export class Spectacle(ctx,benchY) with update(items,dt,time), reset(item), dispose(). Compatibility collections snakes:Map,breads:Map and pile={n,next,mesh,grid:Map}. update creates bounded per-vessel foam, carbon bread, carbon-nitride snake and thermite/volcano deposit/spark visuals from actual mix fx/extent/products only; no chemistry mutation or invented product. Na/K surface motion derives from remaining metal, gas/heat and actual fx, with Na/K-specific flame colors. Luminol glow is driven by core fx.lum; O2/H2/CO2/NO2/NO bubble colors and counts are observations, not gas generation. onPop is emitted once for a completed active K reaction and resets correctly. reset removes/disposes generated objects and every map/pool reference, restores reusable state; dispose releases global pile resources once. No RAF, timer or event listener is installed by either module.
